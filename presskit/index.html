Description

Sync - Sink is a chaotic physics-based local party game for 2–8 players, where each player's smartphone becomes a rowing oar using the mobile companion app. Players scan a QR code on screen to launch the app, join the game, and immediately start paddling.

The twist: the boat only moves where everyone rows it. Players must communicate, coordinate, and survive the increasingly wild river rapids — all while inevitably arguing about who's rowing wrong.
